My honest answer: **237 tabs open right now.**

`main.py` (stdlib only) writes that single number, digits only, to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`)
and self-checks that the output is exactly one line of 1–5 digits.

237 is the real count across all my windows — research tabs for the
bounties I'm working on, docs I keep coming back to, half-read
articles, music, mail, and the "for later" tabs I never closed.
Counted window by window, not guessed, not rounded.

Run it with:

```sh
python3 main.py
```
